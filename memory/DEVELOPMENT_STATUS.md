## 当前限制

- SQL Server镜像未就绪，17个Migration及数据库版Mapper尚未在真实空库执行。
- 甲方数据库备份、完整数据字典、齐总版和钇休版代码尚未进入工作区。
- 数据中心5项、AI最终输出范围、支付/短信通道及部分计算口径仍需甲方确认。
- 当前会员主档范围是API-MEM-001~003；编辑、冻结、标签和归属调整尚未开发。
- 当前主数据范围只覆盖预约所需查询和新建；编辑、停用、职务/分类维护及产品资料尚未开发。
- 预约排班、候补队列和日/周拖拽视图尚未开发。
- 预约转账单、充值、积分、次卡售卡、资产组合结算、手工优惠、代金券、整单冲销、换卡、转赠和退卡资产闭环已完成；服务结算/冲销提成已接入，回访和卡业务提成尚未接入。
- 代金券当前支持金额/折扣、会员、有效期和最低消费；门店/项目/分类/时段限制、客群批量发券及部分退款返券等待甲方规则确认。
- 换卡补差目前保存本地支付事实，未调用真实收款通道；甲方尚需确认降级换卡、零补差和储值补差规则。
- 转赠目前只支持全部剩余资产转移；甲方尚需确认跨门店权限、有效期延长和是否需要审批撤销。
- 提成已自动处理单技师服务、售卡、次卡实耗、换卡补差、退卡和账单冲销；多人分配、店长提成、六种完整模式、阶梯和跨月口径尚未完成。
- 转赠本身不产生提成；转赠后再退卡尚未沿卡谱系追溯原始售卡流水，会保留待处理状态。
- 退卡电子退款目前只保存本地成功事实，不能作为真实通道退款验收；缺规则或缺历史流水时提成状态仍为`PENDING_MODULE`。
- 电子支付真实退款通道尚未接入；当前`trd_payment_refund`只用于本地联调，不能作为生产通道退款验收结果。
