# ITER-43 分类与单位维护

## 目标

补齐产品分类、服务分类和计量单位的管理入口，使产品、服务的新建和编辑不再依赖数据库预置数据。

## 已实现

- 分类支持按产品/服务类型查看全部或仅启用数据，并支持详情、新建、编辑、排序和停用。
- 单位支持查看全部或仅启用数据，并支持详情、新建、编辑、小数精度和停用。
- 分类类型、分类编号和单位编号创建后不可修改；更新使用`row_version`乐观锁，旧版本返回409。
- 产品和服务页面继续只读取启用分类及单位，停用主数据不会删除或改写历史业务引用。
- `/app/catalog/units`合并为“产品分类、服务分类、计量单位”三个页签。
- 新增`catalog:master:view/manage`权限、总部管理员授权及基础资料菜单。
- V1420只增加权限和菜单；业务表、状态约束、唯一约束及`rowversion`沿用既有Migration。

## 验证范围

- 接口测试覆盖分类和单位的新建、详情、编辑停用、启用过滤、管理列表保留及版本冲突。
- Mapper测试覆盖`activeOnly`动态SQL、行版本条件、分类排序和单位精度更新。
- 前端类型检查和生产构建覆盖API契约、路由、权限及管理页。
- `make verify`通过：后端133项测试、前端2项测试、类型检查和生产构建全部成功；最大公共JS约173.85 KB，Compose配置检查通过。

## 明确限制

- 合同未明确多级分类的移动、级联停用和统计口径，首版只维护一级产品/服务分类，不提前虚构规则。
- 单位精度调整只影响后续录入及显示，不改写历史账单、库存或服务物料数据。
- 已被引用的分类和单位不提供物理删除，只能停用。
- SQL Server Migration实跑等待本地Docker权限恢复。
