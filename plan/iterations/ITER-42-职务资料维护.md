# ITER-42 职务资料维护

## 目标

补齐职务新建、编辑和停用能力，为员工、提成方案及后续薪酬计算提供统一职务主数据。

## 已实现

- 新增职务全量/启用列表、详情、新建和更新接口，维护名称、等级、默认服务提成、默认销售提成及状态。
- 职务编号创建后不可修改；比例统一按0~1保存并限制六位小数，页面使用0%~100%展示和录入。
- 管理页展示全部职务；员工与提成页面默认只读取`ACTIVE`职务，停用不删除历史引用。
- 更新使用`org_position.row_version`乐观锁，旧版本提交返回409冲突；SQL Server和memory行为一致。
- 新增`org:position:view/manage`权限、总部管理员授权和系统管理菜单。
- V1410为原表补充`ACTIVE/DISABLED`状态检查约束，不重复建立已有业务字段。

## 验证范围

- 接口测试覆盖新建、详情、比例、编辑停用、启用列表过滤、管理列表保留和版本冲突。
- Mapper测试覆盖动态启用过滤、比例字段及`row_version`更新条件。
- 前端类型检查覆盖职务页面、路由和API契约。
- `make verify`通过：后端131项测试、前端2项测试、类型检查和生产构建全部成功；Compose配置检查通过。

## 明确限制

- 职务默认提成只作为主数据保存；当前结算仍优先使用已生效的版本化提成方案，不在本迭代改动计算口径。
- 已被员工或历史业务引用的职务只能停用，页面不提供物理删除。
- SQL Server Migration实跑等待本地Docker权限恢复。
