# V202607291500 礼品库存、调拨与盘点

## 变更内容

- 新增GIFT分类及`cat_gift`礼品主档，包含计量单位、兑换积分、成本、低库存阈值、状态和rowversion。
- 新增`inv_stock`余额与`inv_stock_ledger`不可变流水；库存只允许已确认调拨、盘点及后续积分兑换改变。
- 新增`inv_transfer/inv_transfer_line`，支持草稿、确认、作废和已确认冲销。
- 新增`inv_count/inv_count_line`，建单保存账面快照，实盘录入后确认盘盈盘亏。
- 新增7项权限及礼品库存、调拨、盘点菜单。

## 数据与并发约束

- 库存余额按`store_id + gift_id`唯一且不得为负；写入前按门店、礼品固定顺序使用`UPDLOCK/HOLDLOCK`，再以rowversion更新。
- 流水满足`after = before + change`，变动不得为0；同一来源行、门店和业务类型只能生成一条流水，原流水只能被冲销一次。
- 调拨确认在单事务内完成调出、调入、两条流水及单据状态；任一侧失败则全量回滚。冲销不改原流水，追加反向流水。
- 盘点创建时锁定并记录账面数量；确认时重新锁定余额，和快照不一致返回409并要求作废重建，防止覆盖盘点期间业务。
- 调拨和盘点创建均使用业务幂等键；单据操作使用rowversion，过期请求不能覆盖新状态。

## 回滚说明

仅在未产生业务数据时可按菜单、角色权限、权限、盘点、调拨、流水、库存、礼品的依赖逆序删除。共享环境产生库存流水后不得直接回滚或删表；应先停止库存写入，导出余额与流水并逐笔对账，再通过新Migration修复。

## 验证

- Flyway从空库顺序执行并校验44个版本脚本和校验和。
- 检查7张业务表、7项权限、4个菜单（含父菜单）和默认GIFT分类。
- 新建礼品后通过盘点录入期初数；调拨确认后双店余额及流水恒等，冲销后余额复原且原流水保留。
- 盘点建单后并发调拨同一礼品，旧盘点确认必须失败；库存不足、重复明细、未来业务日期和过期version必须拒绝。
- `InventoryFlowTest`及`InventoryMapperSqlTest`覆盖内存业务语义和关键SQL锁/参数化结构；SQL Server实库证据必须单独记录，不能以memory测试替代。
