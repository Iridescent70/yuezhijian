# 悦·指间项目计划索引

本目录是后续研发迭代的执行基线。需求范围以 `docs/` 为准，技术实现、目录、质量门槛和迭代过程以 `plan/` 为准。

## 当前有效计划

1. [技术实施计划](./技术实施计划.md)：技术选型、架构、数据规则、初始目录、一个月执行计划及质量门槛。
2. [迭代计划模板](./迭代计划模板.md)：后续每个迭代必须复制该模板建立独立计划。
3. [项目总计划](../docs/项目总计划.md)：项目范围、里程碑、验收、风险及交付标准。

## 计划使用规则

1. 开发前先阅读项目总计划和技术实施计划；代码实现不得偏离已确认的架构边界。
2. 每次迭代在 `plan/iterations/` 新建 `ITER-xx-名称.md`，写清范围、任务、验收、发布和回滚。
3. 技术栈、模块边界、数据库主键、鉴权方式、部署拓扑等基线变化，必须在 `plan/decisions/` 增加ADR并同步修改技术实施计划。
4. 需求状态、代码状态和测试状态必须使用需求编号关联；不能只在聊天记录中确认变更。
5. 文档与代码冲突时先停止相关合并，由技术负责人和产品负责人确认并更新基线。
