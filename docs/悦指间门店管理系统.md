# ***\*三、通用功能要求\****

| 2        | 数据范围     | 支持总部全量、门店范围、本人操作记录等数据范围控制，业务数据按门店、员工、会员和单据归属查询。 |

| 6        | 导入导出     | 导入返回成功数、失败数和失败原因；导出继承查询条件、数据范围和脱敏规则。 |
| 7        | 历史追踪     | 基础资料停用或停售后，不影响历史账单、报表、工资归属和业务审计记录。 |
