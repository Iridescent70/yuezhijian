**功能清单**

本清单列明本期系统交付功能范围，可作为合同附件使用。

**一、范围说明**

**系统范围**

系统覆盖门店结算管理、次卡管理、会员管理、预约管理、统计分析、薪酬提成、移动端、到家服务和系统管理等全业务流程。

**门店经营**

支持多门店数据归属、门店经营核对、员工业务归属、第三方分润和门店目标管理。

**权限安全**

系统按角色、菜单、按钮、数据范围和敏感字段控制访问与操作权限。
